# Crossbow Stays Loaded

Crossbows keep their bolt loaded when you put them away, switch weapons, swim or sit down. Re-equip and fire right away; firing still uses the loaded bolt as usual.

## Configuration

The config file `BepInEx/config/MC.Combat.Crossbow.StaysLoaded.cfg` is created the first time you launch the game with the mod.

| Section | Setting | Default | Description |
|---|---|---|---|
| General | Enabled | `true` | Turn the mod on or off. |

## Multiplayer

Client-side only: only the players who want the feature need to install it. Works on vanilla servers and with vanilla friends.

## Installation

- **Mod manager (r2modman / Thunderstore Mod Manager):** install it from the mod list.
- **Manual:** install [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/), then copy the `MC.Combat.Crossbow.StaysLoaded` folder into `Valheim/BepInEx/plugins/`.

## Compatibility

Built for Valheim 1.0.16.
