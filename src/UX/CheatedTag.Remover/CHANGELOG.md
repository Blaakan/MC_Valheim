# Changelog

## 0.1.0

- Initial version: `cheated_clear` removes the vanilla cheated tag from the whole world (building pieces, creatures,
  stations and their queues, items in containers, on the ground and on stands) and from the items you carry;
  `cheated_scan` counts them without changing anything.
- On a server with the mod, an admin's command runs on the server for the whole world, and every player's game that has
  the mod cleans the items that player carries. On a server without the mod, the commands work on your own items and
  the objects loaded around you.
